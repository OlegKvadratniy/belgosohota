# Подготовка к охотничьему экзамену

Это приложение помогает подготовиться к охотничьему экзамену с использованием вопросов по четырем темам.

## Требования

- Python 3.6+
- Пакет `customtkinter` (уже установлен в виртуальном окружении `.venv`)
- Библиотеки tk и tcl (уже включены в проект в папке `.local/lib`)

## Установка

1. Клонируйте репозиторий или скачайте исходный код.
2. Виртуальное окружение `.venv` уже настроено и содержит все необходимые Python-пакеты.
3. Библиотеки tk и tcl уже скопированы в папку `.local/lib` проекта, поэтому установка системных пакетов не требуется.

## Структура проекта

- `main.py` - точка входа в приложение
- `questions.json` - база вопросов в формате JSON
- `utils/question_loader.py` - загрузка и перемешивание вопросов
- `ui/main_menu_frame.py` - экран главного меню
- `ui/question_frame.py` - экран с вопросами
- `ui/results_frame.py` - экран с результатами

## Формат вопросов (questions.json)

Каждый вопрос имеет следующие поля:
- `topic`: номер темы (1, 2, 3 или 4)
- `question`: текст вопроса
- `options`: массив вариантов ответов (строки)
- `correct_answers`: массив индексов правильных ответов (0-based)
- `is_multiple`: булево значение, указывающее, является ли вопрос множественного выбора (чекбоксы) или одиночного (радиокнопки)
- `explanation`: текст объяснения правильного ответа

## Как запустить

### Быстрый запуск (рекомендуется)

Используйте скрипт-лаунчер, который автоматически настроит все необходимые переменные окружения:

```bash
./launch.sh
```

### Ручной запуск

Если вы хотите запустить приложение вручную, вам нужно установить переменные окружения для tkinter:

```bash
export LD_LIBRARY_PATH="$PWD/.local/lib:$LD_LIBRARY_PATH"
export TCL_LIBRARY="$PWD/.local/lib/tcl8.6"
export TK_LIBRARY="$PWD/.local/lib/tk8.6"
./.venv/bin/python main.py
```

## Использование

1. На главном экране выберите одну из четырех тем для тренировки или нажмите "ЭКЗАМЕН" для прохождения экзамена.
2. В режиме тренировки по теме будут представлены 10 случайных вопросов из выбранной темы.
3. В режиме экзамена будет представлено 10 вопросов: 2 из темы 1, 3 из темы 2, 3 из темы 3 и 2 из темы 4 (в случайном порядке).
4. Для каждого вопроса выберите ответ(ы) и нажмите "Проверить ответ".
5. После проверки вы увидите, был ли ваш ответ правильным, и сможете посмотреть объяснение.
6. После ответа на все вопросы будет показан экран результатов с вашим счетом и вердиктом (для прохождения необходимо правильно ответить на almeno 8 из 10 вопросов).
7. На экране результатов вы можете либо пройти тест снова, либо вернуться в главное меню.

## Примечания

- Варианты ответов перемешиваются случайным образом при каждом запуске вопроса.
- Для вопросов с множественным выбором можно выбрать несколько вариантов.
- Клавиша `X` на клавиатуре показывает/скрывает объяснение текущего вопроса.
